## 반영하지 않은 것

- `mcp/litellm_ops/tests` 픽스처의 `gpt-4o`·`claude-3-sonnet`: 검증 로직용 가짜 값이라 바꾸지 않았다.
- SKILL.md frontmatter 의 `version` 등 표준 밖 키: Claude Code 에서는 동작한다. claude.ai 업로드가 필요해지면 정리한다.
- 도구 호출 파서 이름(`qwen3_xml` 과 `qwen3_coder`): 레시피 안에서도 갈려 실제 서버로 확인해야 한다.
