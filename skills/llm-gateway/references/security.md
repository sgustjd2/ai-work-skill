# security · 게이트웨이 보안

## 키 등급

- 마스터 키(`master_key`)는 admin API 전용이다. 서비스가 쓰지 않는다. 환경변수로만 둔다.
- 서비스·팀은 가상 키를 쓴다. 키마다 모델·예산·레이트 리밋을 건다.
- 키를 발급하면 전체 값이 한 번만 나온다. 즉시 비밀 저장소에 넣고 사람이 다시 보지 않는다.

## 팀과 예산

팀을 만들고 팀 단위로 예산을 건다. 팀 아래 키를 발급하면 사용량이 팀으로 집계된다. 예산 초과 시 알림을 받도록 `alerting` 을 설정한다. 예산 소진은 장애처럼 보이므로 운영 런북에 확인 순서를 둔다.

## 프롬프트 인젝션

사용자 입력을 시스템 지시 자리에 넣지 않는다. 게이트웨이의 guardrails 로 공통 입력 정책을, 앱에서 도메인 규칙을 건다. 둘의 역할을 나눈다.

## PII

개인정보가 프롬프트·응답·로그에 남지 않게 한다. 마스킹 콜백을 쓰거나 본문 로깅을 끈다. 감사 로그에는 누가 어떤 키로 무엇을 호출했는지를 남기되 본문은 남기지 않는다.
