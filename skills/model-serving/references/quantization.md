# quantization · 양자화 선택

양자화는 가중치를 줄여 더 큰 모델을 적은 VRAM 에 올린다. 품질은 조금 떨어진다. 양자화 체크포인트는 llm-compressor(v0.14, 2026-09)로 만든다. AutoAWQ 는 폐기됐다.

## 방식

- FP8(W8A8): 8비트 부동소수. Ada·Hopper·Blackwell(compute capability 8.9 이상)에서 속도·품질 균형이 가장 좋다. Ampere(A100)는 가중치만 FP8 로 두고 계산은 16비트로 한다. 원본 가중치에 `--quantization fp8` 로 즉석 적용도 된다.
- NVFP4·MXFP4: 4비트 부동소수. Blackwell(B200·RTX PRO 6000 등)에서 FP4 연산을 그대로 한다. 그 아래 GPU 에서는 가중치만 4비트(W4A16)로 동작한다. gpt-oss 는 MXFP4 로 배포된다.
- AWQ: 4비트 정수. 품질 손실이 작다. 지금은 llm-compressor 로 만든다.
- GPTQ: 4비트 정수. vLLM 0.30 부터 act-order(`g_idx`)를 무시하므로 act-order 체크포인트는 다시 만든다.
- GGUF: llama.cpp 계열. vLLM 에서는 실험적이다. 로컬·CPU 배포에만 쓴다.
- KV 캐시 FP8: `--kv-cache-dtype fp8`. 가중치와 별개로 긴 컨텍스트·큰 배치에서 효과가 크다.

## 고르는 법

먼저 양자화 없이 올라가는지 본다. 올라가면 그대로 쓴다. VRAM 이 모자랄 때만 양자화한다.

1. H100·H200·L40S 면 FP8 부터 본다.
2. Blackwell 이면 NVFP4 를 본다.
3. A100 이하이거나 더 줄여야 하면 AWQ(4비트).
4. 모델 제작사가 양자화 체크포인트를 공식 배포하면(예: `-FP8`, MXFP4) 그것을 먼저 쓴다.

## 품질 확인

양자화 전후를 골든 셋으로 비교한다. 검색 적중률·정답 포함률이 눈에 띄게 떨어지면 한 단계 위 정밀도로 올린다. 체감이 아니라 수치로 본다. 한국어 품질은 영어 벤치마크와 따로 떨어질 수 있으니 한국어 문항을 반드시 넣는다.
