# quantization · 양자화 선택

양자화는 가중치를 줄여 더 큰 모델을 적은 VRAM 에 올린다. 품질은 조금 떨어진다.

## 방식

- AWQ: 4비트. 활성값 기준으로 중요한 가중치를 보존한다. 추론 품질 손실이 작다. vLLM 지원이 넓다.
- GPTQ: 4비트. 사후 양자화. 커널·버전 호환을 확인한다.
- FP8: 8비트 부동소수. 최신 GPU(H100 등)에서 속도·품질 균형이 좋다.
- GGUF: llama.cpp 계열. CPU·소형 배포에 쓴다. vLLM 서빙에는 위 셋을 먼저 본다.

## 고르는 법

먼저 양자화 없이 올라가는지 본다. 올라가면 그대로 쓴다. VRAM 이 모자랄 때만 양자화한다. 4비트(AWQ)로 시작하고, 품질이 중요하면 FP8 을 본다.

## 품질 확인

양자화 전후를 골든 셋으로 비교한다. 검색 적중률·정답 포함률이 눈에 띄게 떨어지면 한 단계 위 정밀도로 올린다. 체감이 아니라 수치로 본다.
