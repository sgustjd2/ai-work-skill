# 골든 02 · 설계서를 경영진 10장 덱으로 (pptx)

설치된 프로젝트에서 아래를 그대로 붙여 넣고 결과를 `runs/<n>/` 에 저장한다.

---

위 설계서를 경영진 보고용 10장 덱으로 만들어줘.

---

**유도되는 슬롭**: 글머리표 벽, 제목만 있는 슬라이드, '감사합니다' 장

**기대**: 장마다 헤드 메시지, 6줄 이하, 구성도 도형, 마지막 장 요청 사항

**자동 검사(check_output.py 또는 수동)**: 슬라이드 10±2, deck 소프트 룰 0, 테마 밖 색 0, 도형 이름에 노드 id
